# Gather before choosing the Deck

Create the Session and gather Participants in its Lobby before settling the shared Deck. Every Participant can contribute optional interests and explicitly confirm Ready; shared interests combine, dietary requirements all apply, and the Host starts the round once everyone is Ready. This replaces Host-only setup to give everyone influence, accepting more coordination and the need to represent a Session before its Deck is chosen.

The Deck stays fixed during swiping so everyone judges the same alternatives. Late joiners normally use that Deck; a conflicting dietary requirement instead requires a Host-confirmed return to preferences and a fresh round before the newcomer participates.
